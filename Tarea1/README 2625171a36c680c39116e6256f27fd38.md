# README

**a. Navegación de directorios**

1. **cd** (Cambiar directorio):
    
    ```bash
    cd /tmp
    ```
    
    - **Propósito**: Cambia el directorio de trabajo actual a `/tmp`.
    - **Salida esperada**: Ninguna, pero estarás en `/tmp`.
2. **ls** (Listar contenido):
    
    ```bash
    ls
    ```
    
    - **Propósito**: Muestra los archivos y directorios en el directorio actual.
    - **Salida esperada**: Lista de archivos en `/tmp` (puede variar).
3. **pwd** (Imprimir directorio actual):
    
    ```bash
    pwd
    ```
    
    - **Propósito**: Muestra la ruta completa del directorio actual.
    - **Salida esperada**: Algo como `/tmp`.

### **b. Manipulación de archivos**

1. **touch** (Crear archivo vacío):
    
    ```bash
    touch ejemplo.txt
    ```
    
    - **Propósito**: Crea un archivo vacío llamado `ejemplo.txt`.
    - **Salida esperada**: Ninguna, pero `ls` mostrará `ejemplo.txt`.
2. **cp** (Copiar archivo):
    
    ```bash
    cp ejemplo.txt ejemplo_copia.txt
    ```
    
    - **Propósito**: Copia `ejemplo.txt` a `ejemplo_copia.txt`.
    - **Salida esperada**: Ninguna, pero `ls` mostrará ambos archivos.
3. **mv** (Mover o renombrar archivo):
    
    ```bash
    mv ejemplo_copia.txt ejemplo_nuevo.txt
    ```
    
    - **Propósito**: Renombra `ejemplo_copia.txt` a `ejemplo_nuevo.txt`.
    - **Salida esperada**: Ninguna, pero `ls` mostrará `ejemplo_nuevo.txt`.
4. **rm** (Eliminar archivo):
    
    ```bash
    rm ejemplo_nuevo.txt
    ```
    
    - **Propósito**: Elimina `ejemplo_nuevo.txt`.
    - **Salida esperada**: Ninguna, pero `ls` ya no mostrará el archivo.

### **c. Visualización de contenido**

Crea un archivo de prueba con contenido:

```bash
echo "Este es un archivo de prueba" > prueba.txt
```

1. **cat** (Mostrar contenido completo):
    
    ```bash
    cat prueba.txt
    ```
    
    - **Propósito**: Muestra todo el contenido de `prueba.txt`.
    - **Salida esperada**: `Este es un archivo de prueba`.
2. **more** (Mostrar contenido página por página):
    
    ```bash
    more prueba.txt
    ```
    
    - **Propósito**: Muestra el contenido con paginación (útil para archivos largos).
    - **Salida esperada**: Similar a `cat`, pero interactivo si el archivo es grande.
3. **less** (Navegar por el contenido):
    
    ```bash
    less prueba.txt
    ```
    
    - **Propósito**: Permite navegar por el contenido con teclas (usa `q` para salir).
    - **Salida esperada**: Similar a `more`, pero con más opciones de navegación.

### **d. Gestión de permisos**

1. **chmod** (Cambiar permisos):
    
    ```bash
    chmod 644 prueba.txt
    
    ```
    
    - **Propósito**: Establece permisos de lectura/escritura para el propietario y solo lectura para otros.
    - **Salida esperada**: Ninguna, pero verifica con `ls -l` (mostrará `rw-r--r--`).
2. **chown** (Cambiar propietario):
    
    ```bash
    sudo chown root prueba.txt
    
    ```
    
    - **Propósito**: Cambia el propietario del archivo a `root` (requiere permisos de superusuario).
    - **Salida esperada**: Ninguna, pero verifica con `ls -l` (mostrará `root` como propietario).

### **Desarrollar el script Bash `simulacion_crear_contenedores.sh`**

1. Crear el archivo del script:
    
    ```bash
    touch simulacion_crear_contenedores.sh
    ```
    
2. Editar el archivo como `nano`:
    
    ```bash
    nano simulacion_crear_contenedores.sh
    ```
    
3. Colocar el siguiente código en el archivo:

```bash
#!/bin/bash
NUM_FILES=$((RANDOM % 4 + 1))
CARNET="202204496"
# Array de nombres aleatorios para los archivos
NAMES=("alpha" "beta" "gamma" "delta" "epsilon" "zeta")
# Crear los archivos
for ((i=1; i<=NUM_FILES; i++))
do
    # Seleccionar un nombre aleatorio del array
    RANDOM_NAME=${NAMES[$((RANDOM % ${#NAMES[@]}))]}
    # Generar el nombre del archivo
    FILENAME="contenedor_${CARNET}_${RANDOM_NAME}.txt"
    # Crear el archivo y escribir su nombre como contenido
    echo "$FILENAME" > "$FILENAME"
    echo "Archivo creado: $FILENAME"
done
echo "Se crearon $NUM_FILES archivos."
```

1. Guardar y cierrar el archivo (en `nano`, presiona `Ctrl+O`, `Enter`, luego `Ctrl+X`).
2. Darle permisos de ejecución al script:
    
    ```bash
    chmod +x simulacion_crear_contenedores.sh
    ```
    

---

### **Ejecutar script (Creación de Contenedores)**

Ejecutar el script:

```bash
./simulacion_crear_contenedores.sh
```

**Salida esperada**: El script creará entre 1 y 4 archivos con nombres como `contenedor_123456_alpha.txt`, `contenedor_123456_beta.txt`. **Cada archivo contendrá su propio nombre como contenido.** La terminal mostrará algo como:

```
Archivo creado: contenedor_202204496_alpha.txt
Archivo creado: contenedor_202204496_beta.txt
Se crearon 2 archivos.
```
